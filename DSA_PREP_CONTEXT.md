### 4. Daily Routine (1.5–2 hours/day)
```
30 min — Solve 1 problem (attempt yourself, no hints for 20 min)
15 min — Study optimal solution if stuck
15 min — Re-code optimal solution from scratch
30 min — Solve 1 more problem (same pattern)
Weekend: 1 timed mock (45 min, unseen problem)
```

### 5. Rules
- Don't spend >30 min stuck — learn the pattern, then practice
- Write by hand first (no autocomplete)
- Always analyze Time + Space complexity
- Revisit failed problems after 3-5 days
- Java only

### 6. The 15 Core Patterns
```
1.  Hashmap / HashSet         — frequency counting, lookup
2.  Two Pointers              — sorted arrays, palindromes
3.  Sliding Window            — subarrays, substrings
4.  Binary Search             — sorted data, search space
5.  Stack                     — matching, monotonic, next greater
6.  Linked List tricks        — fast/slow pointer, reversal
7.  BFS                       — level-order, shortest path
8.  DFS                       — paths, connected components
9.  Backtracking              — subsets, permutations, combinations
10. Heap / Priority Queue     — top-K, merge K sorted
11. Greedy                    — intervals, scheduling
12. DP — 1D                   — linear decisions
13. DP — 2D                   — grid paths, string matching
14. Trie                      — prefix search, autocomplete
15. Union Find                — connected components, cycle detection
```
